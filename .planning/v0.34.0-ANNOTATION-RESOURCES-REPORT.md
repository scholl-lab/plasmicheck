# Variant Annotation Resources Report

> **Date:** 2026-02-16
> **Purpose:** Evaluate external databases for enhancing variant annotations, with focus on ontology mapping (VARIO, HPO, SO), data accessibility, and practical integration approaches.

---

## Executive Summary

This report evaluates **23+ variant annotation resources** across six categories for integration into an annotation pipeline. Key findings:

1. **VARIO (Variation Ontology) is orphaned** with no active maintainer. Major tools (SnpEff, VEP) use **Sequence Ontology (SO)** instead. VARIO mapping requires manual curation or the VariOtator SOAP service.
2. **Best free, open resources:** ClinVar, gnomAD, dbNSFP, Gene2Phenotype, PanelApp, Orphanet, InterVar, Open Targets
3. **Best aggregators:** MyVariant.info (free API), VarSome (paid), Ensembl VEP (free, plugin ecosystem)
4. **Recommended core stack:** SnpEff/SnpSift + ClinVar + dbNSFP + gnomAD + InterVar covers ~95% of annotation needs with entirely free resources

## Tier 1: Essential Resources (High Impact, Free Access)

### 1. ClinVar
**What:** NCBI's archive of variant-disease interpretations with clinical significance ratings.

**Data access:**
- Weekly VCF downloads (GRCh37/38): `ftp.ncbi.nlm.nih.gov/pub/clinvar/vcf_GRCh38/`
- E-utilities API (esearch, esummary, efetch)
- Monthly comprehensive XML releases

**Key fields:** CLNSIG (pathogenicity), CLNDN (disease name), CLNREVSTAT (review confidence), CLNDISDB (cross-DB IDs)

**Ontology mapping:** Rich cross-references via MedGen hub to HPO, OMIM, Orphanet, Mondo, SNOMED CT, SO. MedGen mapping files available (`MedGen_HPO_Mapping.txt`, `MedGen_HPO_OMIM_Mapping.txt`).

**SnpEff/SnpSift integration:**
```bash
# Download
wget https://ftp.ncbi.nlm.nih.gov/pub/clinvar/vcf_GRCh38/clinvar.vcf.gz{,.tbi}

# Annotate
java -jar SnpSift.jar annotate -info ALLELEID,CLNDN,CLNSIG,CLNVC clinvar.vcf.gz input.vcf > output.vcf
```

**Python:** cyvcf2 (6.9x faster than pysam), Biopython Entrez, MyVariant.py

**Update frequency:** Weekly (website), monthly (comprehensive releases)

**Verdict:** **Must-have.** Free, comprehensive, natively VCF, direct SnpSift integration.

---

### 2. gnomAD v4
**What:** Population-scale allele frequencies from 183.6M exome + 759.3M genome variants.

**Data access:**
- GraphQL API: `gnomad.broadinstitute.org/api`
- Cloud downloads: Google Cloud (`gs://gcp-public-data--gnomad`), AWS, BigQuery
- VCF and Hail Table formats

**Key fields:** AF, AF_popmax, FAF (filtering AF), AN, AC, nhomalt

**Constraint scores:** pLI (binary LoF intolerance), LOEUF (continuous, recommended: <0.6 for constrained genes in v4), missense/synonymous Z-scores

**SnpEff/SnpSift integration:**
```bash
java -jar SnpSift.jar annotate -info AF,AF_popmax gnomad.vcf.bgz input.vcf > output.vcf
```

**Python:** gnomad-db (SQLite), Hail (official), direct GraphQL queries

**Verdict:** **Must-have.** Gold standard for population frequency filtering. Free, open.

---

### 3. dbNSFP v4.8
**What:** Pre-computed functional predictions for ALL possible non-synonymous and splice-site SNVs (~85M variants).

**Data access:** Bulk download (~25GB compressed per genome build)

**Content:** 46 prediction algorithms including SIFT, PolyPhen-2, CADD, REVEL, BayesDel, MutFormer, SpliceAI. Plus conservation scores (GERP++, phyloP, phastCons) and population frequencies.

**SnpEff/SnpSift integration:**
```bash
# Prepare
bgzip dbNSFP4.8a_grch38.txt && tabix -s 1 -b 2 -e 2 dbNSFP4.8a_grch38.txt.gz

# Annotate (select fields)
java -jar SnpSift.jar dbnsfp \
  -f SIFT_score,Polyphen2_HDIV_score,CADD_phred,REVEL_score,MetaRNN_score \
  -db dbNSFP4.8a_grch38.txt.gz input.vcf > output.vcf
```

**Verdict:** **Must-have.** One download gives you 46 predictors. SnpSift-ready.

---

### 4. Ensembl VEP (Variant Effect Predictor)
**What:** Comprehensive consequence prediction with 40+ plugins for ClinVar, dbNSFP, CADD, SpliceAI, gnomAD, LOFTEE.

**Data access:** Local install (Perl/C++), REST API, web interface

**Integration:** Plugin architecture means a single VEP run can aggregate multiple databases:
```bash
vep -i input.vcf -o output.vcf --cache --offline \
  --plugin CADD,/data/cadd.tsv.gz \
  --plugin SpliceAI,snv=/data/spliceai.vcf.gz \
  --plugin dbNSFP,/data/dbNSFP.gz,SIFT_score,REVEL_score \
  --everything
```

**Verdict:** **Recommended as primary annotator** if building a full pipeline. Plugin ecosystem handles most annotation in one pass.

## Tier 2: High-Value Specialized Resources

### 5. OMIM
**What:** Expertly curated gene-disease relationships, inheritance patterns, allelic variants.

**Data access:**
- API (JSON/XML) with registration key (academic free, commercial paid)
- `mim2gene.txt` freely available without registration (gene-to-MIM mapping)
- Weekly data refresh required if storing locally

**Key data:** 15,500+ genes, 26,200+ allelic variants, 7,800+ phenotypes with inheritance patterns (AD, AR, XL, etc.)

**Ontology mapping:** Historical source for HPO development. 93,885 HPO annotations derived from OMIM Clinical Synopsis. Cross-references to MedGen, Mondo, UMLS.

**Limitations:** API key annual renewal, no redistribution allowed, commercial license required for for-profit use.

**Verdict:** **High value for gene-disease context.** Use `mim2gene.txt` (free) for basic mapping; API for full clinical synopsis.

---

### 6. DECIPHER
**What:** Clinical genomics database for rare disease with phenotype-linked variants (SNVs, CNVs, SVs, STRs).

**Data access:**
- API with dual-key authentication (client + account keys)
- Bulk download with Data Access Agreement
- JSON:API specification

**HPO integration:** Bidirectional -- DECIPHER both uses and contributes to HPO development. 60+ recurrent syndromes annotated with HPO terms.

**Access model:** Tiered (public open-consent data, registered user data, project-specific data).

**Verdict:** **Excellent for rare disease.** Strong HPO integration. Requires signed agreement for bulk data.

---

### 7. Gene2Phenotype (G2P / DDG2P)
**What:** Curated gene panels for developmental disorders, eye, cardiac, skeletal, skin, cancer.

**Data access:**
- Free CSV downloads from EBI
- VEP G2P plugin for direct variant filtering
- Panels: DDG2P, Eye G2P, Cardiac G2P, Skeletal G2P, Skin G2P, Cancer G2P

**Key data:** Allelic requirements (monoallelic, biallelic, X-linked), mutational consequences (LoF, GoF), confidence levels.

```bash
wget https://www.ebi.ac.uk/gene2phenotype/downloads/DDG2P.csv.gz
```

**Verdict:** **Essential for developmental disorder work.** Free, well-curated, VEP plugin available.

---

### 8. PanelApp (Genomics England)
**What:** 400+ community-curated clinical gene panels with traffic-light confidence scoring.

**Data access:** REST API (free, open)
```python
import requests
panel = requests.get("https://panelapp.genomicsengland.co.uk/api/v1/panels/484/").json()
genes = [g['gene_data']['gene_symbol'] for g in panel['genes'] if g['confidence_level'] == '3']
```

**Verdict:** **Excellent for clinical filtering.** Free API, well-maintained, covers broad disease categories.

---

### 9. Orphanet / Orphadata
**What:** Comprehensive rare disease database with ORDO (Orphanet Rare Disease Ontology).

**Data access:**
- Orphadata: free XML/JSON datasets
- SPARQL endpoint for linked data queries
- HOOM module: HPO-ORDO mappings with phenotype frequencies

**Ontology mapping:** Direct HPO integration via HOOM. Cross-references to OMIM, UniProt, HGNC, Ensembl.

**License:** CC BY-ND 3.0 (free, attribution required, no derivatives)

**Verdict:** **Essential for rare disease ontology work.** HOOM module directly maps HPO to diseases.

---

### 10. denovo-db v1.6.1
**What:** 46,612 parent-child trios with de novo variants from ASD and DD cohorts.

**Data access:** TSV/VCF downloads from `denovo-db.gs.washington.edu`

**Content:** 30 fields per variant including functional predictions (PolyPhen, SIFT, CADD, LoF), population frequencies, phenotype, validation status. 615 candidate genes at FDR < 0.05.

**Limitation:** SSC data restricted to autism/DD research. No API.

**Verdict:** **Valuable for neurodevelopmental disorder research.** Pre-computed predictions included.

## Tier 3: Specialized / Complementary Resources

### 11. CADD Scores
Pre-computed deleteriousness for all SNVs. API for small queries, bulk download for pipelines. Also available through dbNSFP and VEP plugins.

### 12. REVEL Scores
Ensemble of 13 tools for missense pathogenicity. Download + tabix. Also in dbNSFP. Best for rare variants (AF < 0.5%).

### 13. SpliceAI
Deep learning splice predictions. Python package (`pip install spliceai`), VEP plugin, pre-computed scores. Also in dbNSFP.

### 14. InterVar
Open-source ACMG/AMP variant interpretation. Python CLI tool. Competitive with commercial tools (Franklin, VarSome).
```bash
python InterVar.py -i input.vcf -o output
```

### 15. UniProt
Protein variant annotations (humsavar). REST API, CC BY 4.0. Good for protein-level functional impact. ~30,000 curated human variants.

### 16. Open Targets
GraphQL API for gene-disease-drug associations. Apache 2.0 license. Integrates GWAS, functional genomics, drug target data.

### 17. DisGeNET
Gene-disease and variant-disease associations. REST API (academic free). One of largest gene-disease databases.

### 18. MyVariant.info
**Aggregator API** querying ClinVar, CADD, dbSNP, gnomAD, dbNSFP, COSMIC in one call. Free, open. Excellent for prototyping.
```python
import myvariant
mv = myvariant.MyVariantInfo()
result = mv.getvariant("chr1:g.35367G>A")
```

## VARIO Ontology: Assessment

### Current Status
**VARIO is orphaned** (no active maintainer per OBO Foundry). Contains 384 terms across 8 levels covering DNA/RNA/protein variation effects, consequences, and mechanisms.

### Adoption Reality
- **No major annotation tool uses VARIO.** SnpEff, VEP, and ANNOVAR all use **Sequence Ontology (SO)**.
- **LOVD** is the only major database designed to work with VARIO.
- **VariOtator** is the sole annotation tool (SOAP web service, accepts HGVS input).

### Practical SO-to-VARIO Mapping

If VARIO terms are needed, manual mapping from SO is required:

| SO Term | SO ID | VARIO Concept |
|---------|-------|---------------|
| missense_variant | SO:0001583 | DNA substitution + protein property change |
| frameshift_variant | SO:0001589 | DNA indel + protein structure loss |
| stop_gained | SO:0001587 | DNA substitution + protein function loss |
| splice_site_variant | SO:0001629 | RNA processing effect |

### Recommendation
**Use Sequence Ontology as primary**, which has universal tool support. Add VARIO enrichment only if submitting to LOVD or if research specifically requires mechanistic annotation. The VariOtator SOAP service can convert HGVS notations to VARIO terms for selective enrichment.

## Recommended Integration Architecture

### Minimal High-Impact Stack (All Free)

```
Input VCF
    |
    v
[1] SnpEff (SO consequence terms)
    |
    v
[2] SnpSift + ClinVar VCF (clinical significance)
    |
    v
[3] SnpSift + dbNSFP (46 predictors: CADD, REVEL, SpliceAI, etc.)
    |
    v
[4] SnpSift + gnomAD VCF (population frequencies)
    |
    v
[5] InterVar (ACMG/AMP classification)
    |
    v
[6] Gene panel filtering (G2P, PanelApp API)
    |
    v
[7] Phenotype matching (HPO via ClinVar/OMIM/Orphanet cross-refs)
    |
    v
Annotated + Classified Variants
```

### Full Pipeline Commands

```bash
# Step 1: Variant effects
java -Xmx8g -jar snpEff.jar GRCh38.99 input.vcf > step1.vcf

# Step 2: ClinVar
java -jar SnpSift.jar annotate clinvar.vcf.gz step1.vcf > step2.vcf

# Step 3: dbNSFP (selected fields)
java -jar SnpSift.jar dbnsfp \
  -f SIFT_score,Polyphen2_HDIV_score,CADD_phred,REVEL_score,MetaRNN_score,SpliceAI_pred \
  -db dbNSFP4.8a_grch38.txt.gz step2.vcf > step3.vcf

# Step 4: gnomAD
java -jar SnpSift.jar annotate -info AF,AF_popmax gnomad.vcf.bgz step3.vcf > step4.vcf

# Step 5: ACMG interpretation
python InterVar.py -i step4.vcf -o classified

# Step 6: Extract to table
java -jar SnpSift.jar extractFields step4.vcf \
  CHROM POS REF ALT "ANN[0].GENE" "ANN[0].EFFECT" "ANN[0].HGVS_P" \
  CLNSIG CLNDN AF dbNSFP_CADD_phred dbNSFP_REVEL_score > annotations.tsv
```

### Python Aggregation Layer

```python
# For real-time or selective enrichment
import myvariant
mv = myvariant.MyVariantInfo()

# Batch query (up to 1000 per request)
variants = mv.getvariants(
    ['rs58991260', 'rs2500'],
    fields='dbnsfp.cadd,clinvar.rcv,gnomad_genome'
)

# Gene panel check
import requests
panel = requests.get("https://panelapp.genomicsengland.co.uk/api/v1/panels/484/").json()
green_genes = {g['gene_data']['gene_symbol'] for g in panel['genes'] if g['confidence_level'] == '3'}
```

## Key Recommendations

1. **Start with SnpEff + ClinVar + dbNSFP + gnomAD** -- covers most annotation needs with free tools
2. **Use Sequence Ontology** as primary ontology (universal tool support vs. orphaned VARIO)
3. **Add InterVar** for automated ACMG/AMP classification (free, open-source)
4. **Use PanelApp API** for clinical indication-specific gene filtering
5. **Use MyVariant.info** for prototyping and ad-hoc queries before building full pipeline
6. **Consider VEP** if you want a single-tool solution with plugin extensibility
7. **For HPO mapping:** ClinVar -> MedGen -> HPO is the most robust path; Orphanet HOOM module for rare diseases
8. **Avoid VARIO dependency** unless specifically required for LOVD submission
9. **dbNSFP subsumes** CADD, REVEL, SpliceAI and 43 other predictors -- download once, get everything
10. **Commercial tools** (VarSome, Franklin, HGMD Pro) add value but are not essential for a research pipeline
