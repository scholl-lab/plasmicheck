**A. Restructure summary_template.html with collapsible sections:**

Replace the current flat layout with Bootstrap 4 collapsible card sections. Use `data-toggle="collapse"` and `data-target` (Bootstrap 4.5.2 syntax, NOT Bootstrap 5 `data-bs-*`). All sections default to open (`class="collapse show"`).

Section ordering (as per CONTEXT.md decisions):
1. **Contamination Analysis** (existing content: ratio heatmap, boxplot, combined table, verdict table, ratio table, p-value table)
2. **Coverage Outside Insert** (new: CoverageOutsideINSERT heatmap + boxplot) -- this is a contamination indicator but gets its own section per REPT-04
3. **Coverage Analysis** (new: backbone mean depth heatmap, backbone breadth heatmap) -- REPT-06, REPT-07
4. **Mismatch Analysis** (new: MismatchesNearINSERT heatmap) -- REPT-05
5. **Resistance Gene Coverage** (new: flat table) -- REPT-08

Each new section uses conditional rendering with Jinja2:
```html
{% if coverage_outside_heatmap_content %}
<div class="card mb-3">
  <div class="card-header" id="headingCovOutside">
    <h5 class="mb-0">
      <button class="btn btn-link" data-toggle="collapse" data-target="#collapseCovOutside" aria-expanded="true">
        Coverage Outside Insert
      </button>
    </h5>
  </div>
  <div id="collapseCovOutside" class="collapse show">
    <div class="card-body">
      <div class="plot">
        {% if interactive %}
          {{ coverage_outside_heatmap_content|safe }}
        {% else %}
          <img src="{{ coverage_outside_heatmap_content }}" alt="CoverageOutsideINSERT Heatmap">
        {% endif %}
      </div>
      {% if coverage_outside_boxplot_content %}
      <div class="plot">
        {% if interactive %}
          {{ coverage_outside_boxplot_content|safe }}
        {% else %}
          <img src="{{ coverage_outside_boxplot_content }}" alt="CoverageOutsideINSERT Boxplot">
        {% endif %}
      </div>
      {% endif %}
    </div>
  </div>
</div>
{% endif %}
```
