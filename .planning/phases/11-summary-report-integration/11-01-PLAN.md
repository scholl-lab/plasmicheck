```python
DEPTH_HEATMAP_CAP: float = PLOT_CONFIG.get("depth_heatmap_cap", 100.0)
```

**2. Add `create_metric_heatmap_data()` function:**
A generic helper that extracts a single metric category from summary_df and pivots it to Sample x Plasmid grid.
- Parameters: `summary_df: pd.DataFrame, metric_category: str`
- Filter summary_df where Category == metric_category
- If filtered df is empty, return `pd.DataFrame()` (graceful degradation for pre-v0.33.0 data)
- Convert Value to numeric with `pd.to_numeric(..., errors="coerce")`
- Pivot: `index="Sample", columns="Plasmid", values="Value"` and round to ROUND_DECIMALS
- Return the pivoted DataFrame

**3. Add `plot_metric_heatmap()` function:**
A generic Plotly heatmap generator for any Sample x Plasmid metric grid.
- Parameters: `metric_data: pd.DataFrame, output_dir: str, metric_name: str, vmax: float | None = None, static_report: bool = False, plot_backend: str = "plotly"`
- If metric_data is empty, log warning and return `("", None)`
- Use blue-to-red color scale matching existing ratio heatmap: `[[0.0, PLOT_CONFIG["colors"]["not_contaminated"]], [1.0, PLOT_CONFIG["colors"]["contaminated"]]]`
- If vmax is provided, clip data with `.clip(upper=vmax)` before plotting
- Create `px.imshow()` with `height=PLOT_DIMENSIONS["height"]`, `aspect="auto"`, title=f"Heatmap of {metric_name} by Sample and Plasmid"
- Update layout: xaxis_title="Plasmid", yaxis_title="Sample", tickangle=PLOT_CONFIG["xticks_rotation"], tickfont size 9, tickmode="linear"
- `fig.update_coloraxes(showscale=False)`
- Save interactive HTML to `{output_dir}/plots/heatmap_{slug}.html` where slug = metric_name.lower().replace(" ", "_")
- For static_report: if plot_backend == "matplotlib", lazy import `generate_metric_heatmap_matplotlib` from matplotlib_backend; else use `fig.write_image()`
- Save PNG to `{output_dir}/plots/heatmap_{slug}.png`
- Return `(html_filename, png_filename_or_None)`

**4. Add `plot_coverage_outside_insert_boxplot()` function:**
Boxplot for CoverageOutsideINSERT distribution across plasmids (similar to existing plot_boxplot but for coverage metric).
- Parameters: `summary_df: pd.DataFrame, output_dir: str, static_report: bool = False, plot_backend: str = "plotly"`
- Extract CoverageOutsideINSERT rows from summary_df, convert Value to numeric
- If empty, return `("", None)`
- Pivot to Sample x Plasmid, then melt back for boxplot
- Create `px.box()` with x="Plasmid", y="Value", points="all", hover_data={"Sample": True}, title="CoverageOutsideINSERT Distribution by Plasmid"
- Update layout: yaxis_title="Coverage Outside Insert", height=800
- Save interactive HTML to `{output_dir}/plots/boxplot_coverage_outside_insert.html`
- For static_report: if plot_backend == "matplotlib", lazy import `generate_coverage_boxplot_matplotlib`; else use `fig.write_image()`
- Return `(html_filename, png_filename_or_None)`

**5. Add `create_resistance_gene_table()` function:**
Extracts resistance gene data from summary_df into a flat table.
- Parameters: `summary_df: pd.DataFrame`
- Check for ResistanceGenesAvailable rows; if all are "false" or missing, return empty DataFrame with columns ["Sample", "Plasmid", "Gene Name", "Mean Depth", "Breadth (%)"]
- Find ResistanceGenes rows; for each, split gene names by comma
- For each gene, look up `ResGene_{sanitized_name}_MeanDepth` and `ResGene_{sanitized_name}_Breadth` rows (sanitize: replace "/" and " " with "_")
- Build list of dicts with Sample, Plasmid, Gene Name, Mean Depth (float), Breadth (%) (float)
- Return pd.DataFrame(rows)

**6. Add to config.json:**
Inside `plot_summary`, add `"depth_heatmap_cap": 100` (after `marker_style`).

All new functions must have full type annotations and docstrings.
