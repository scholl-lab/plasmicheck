**compare_alignments.py changes:**

The function `compare_alignments()` currently derives `cdna_positions_file` from `os.path.dirname(output_basename)`:
```python
cdna_positions_file = os.path.join(os.path.dirname(output_basename), "cDNA_positions.txt")
```

And `locate_genbank_file` also uses `os.path.dirname(output_basename)`.

With the new structure, output_basename is in `data/` but cDNA_positions.txt is also in `data/`, so the dirname derivation STILL works (both are in data_dir). However, this is fragile. Add an optional `cdna_positions_file` parameter:

```python
def compare_alignments(
    plasmid_bam: str,
    human_bam: str,
    output_basename: str,
    threshold: float = DEFAULT_THRESHOLD,
    genbank_file: str | None = None,
    cdna_positions_file: str | None = None,  # NEW
) -> None:
```

If `cdna_positions_file` is None, fall back to the existing dirname derivation. Update run_pipeline.py to pass `cdna_positions_file=str(paths.cdna_positions)` explicitly.

**resistance_gene_detection.py changes:**

Update `locate_genbank_file()` to also search in a `references/` subdirectory:

# Check for .gb file in output_dir
gb_files = glob.glob(os.path.join(output_dir, "*.gb"))
