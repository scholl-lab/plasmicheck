**In `plasmicheck/cli.py`:**

Add two new arguments to the `parser_pipeline` subcommand (add them near the end, after `--threads`):

```
--cache-dir   Path to cache directory (default: ~/.plasmicheck/cache)
--no-cache    Disable caching for this run (store_true)
```

Pass both to `run_pipeline()` call:
```python
cache_dir=args.cache_dir,
no_cache=args.no_cache,
```

**In `plasmicheck/scripts/run_pipeline.py`:**

1. Add `run_pipeline` parameters: `cache_dir: str | None = None` and `no_cache: bool = False`

2. Import CacheManager: `from plasmicheck.cache_manager import CacheManager`

3. Initialize cache early in `run_pipeline()`, after plan is built but before execution:
```python
cache: CacheManager | None = None
if not no_cache:
    try:
        cache_path = Path(cache_dir) if cache_dir else Path.home() / ".plasmicheck" / "cache"
        cache = CacheManager(cache_path)
    except (OSError, PermissionError) as e:
        logging.warning(f"Cache directory inaccessible: {e}. Disabling cache for this run.")
        cache = None
```

4. **Index caching** — In the per-combination loop where `create_indexes(plasmid_fasta, overwrite)` is called (around line 587):
   - Before calling `create_indexes`, check cache: `if cache and (cached := cache.get_index(plasmid_fasta)):`
   - On cache hit: copy cached .mmi to expected `plasmid_index` path using `shutil.copy2`. Also check for .fai (samtools index) — if not cached, still run `create_indexes` (the function handles existing .mmi gracefully).
   - On cache miss: call `create_indexes` as before, then `if cache: cache.put_index(plasmid_fasta, plasmid_index)`
   - This replaces the within-run dedup that `built_indexes` provided for plasmid indexes. The `built_indexes` set can remain for the human index (which is built once upfront and doesn't need cross-run caching since it's a large shared reference).

5. **Spliced alignment caching** — In the spliced alignment section (around line 600):
   - Before calling `spliced_alignment()`, check: `if cache and (cached_spliced := cache.get_spliced(plasmid_fasta, human_fasta)):`
   - On cache hit: copy cached files to expected paths (spliced BAM -> `spliced_bam`, spliced FASTA -> `spliced_fasta`, cDNA positions -> `cdna_positions_file`). Skip `spliced_alignment()`, `extract_human_reference()`, and `extract_plasmid_cdna_positions()` calls. Log at INFO level.
   - On cache miss: run spliced alignment as before, then `if cache: cache.put_spliced(plasmid_fasta, human_fasta, spliced_bam, spliced_fasta, cdna_positions_file)`
   - Note: `spliced_fasta` needs indexing after cache hit too — still call `create_indexes(spliced_fasta, overwrite)` after restoring from cache. The index for spliced_fasta itself is small and fast to build, not worth caching separately.

6. **Graceful degradation** — Wrap all cache.get/put calls in try/except (OSError, PermissionError). On failure, log warning and continue without cache. Do NOT let cache errors stop the pipeline.

Keep the existing `built_indexes` set for tracking human index (backward compatibility, still useful for the upfront human index build). The cache adds cross-run persistence on top of within-run dedup.
