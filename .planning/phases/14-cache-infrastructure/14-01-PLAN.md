  <action>
Create `plasmicheck/cache_manager.py` with a `CacheManager` class. Follow the skeleton from 14-RESEARCH.md closely but implement the full feature set:

**Constructor (`__init__`):**
- Accept `cache_root: Path` and `size_limit_gb: float = 10.0`
- Create subdirectories: `indexes/` and `spliced/` under cache_root
- Load or initialize JSON manifest (`manifest.json` at cache_root)
- Wrap directory creation in try/except for OSError/PermissionError — raise with clear message if cache dir is inaccessible
- Use `logging.getLogger(__name__)` for all log calls

**Manifest management:**
- `_load_manifest() -> OrderedDict` — load from disk, handle JSONDecodeError/OSError by logging warning and returning empty OrderedDict
- `_save_manifest() -> None` — atomic write using tempfile.NamedTemporaryFile in same directory + os.replace. Manifest JSON schema: `{"version": "1.0", "entries": {...}}`

**Index cache (get/put):**
- `get_index(input_fasta: str) -> Path | None` — compute MD5 of input_fasta via `calculate_md5`, look up in manifest. On hit: verify file exists and size matches manifest (if not, delete stale entry, return None). Update last_access, move_to_end, save manifest, log INFO "Cache HIT". On miss: log INFO "Cache MISS", return None.
- `put_index(input_fasta: str, index_path: str) -> None` — compute MD5, atomic copy index_path to `indexes/{md5}.mmi`, update manifest with path/size/created/last_access/type="index", evict if needed.

**Spliced alignment cache (get/put):**
- `get_spliced(plasmid_fasta: str, human_fasta: str) -> dict[str, Path] | None` — compute combined cache key: `hashlib.md5(f"{plasmid_md5}:{human_md5}".encode()).hexdigest()`. Return dict with keys "bam", "fasta", "cdna_positions" pointing to cached files, or None on miss. Same validation as get_index.
- `put_spliced(plasmid_fasta: str, human_fasta: str, bam_path: str, fasta_path: str, cdna_path: str) -> None` — atomic copy all three files to `spliced/{combined_md5}.{ext}`, single manifest entry with total size of all three files.

**Atomic copy helper:**
- `_atomic_copy(source: str, target: Path) -> None` — use tempfile.NamedTemporaryFile(dir=target.parent, delete=False) + shutil.copyfileobj + os.replace. Clean up temp file in except block if copy fails.

**LRU eviction:**
- `_evict_if_needed() -> None` — sum all entry sizes, while total > size_limit pop oldest (popitem(last=False)), delete cached files (unlink missing_ok=True), log WARNING for each eviction. Save manifest after eviction.

**Info/clean methods (for CLI in Plan 03):**
- `info() -> dict` — return dict with total_entries, total_size_bytes, cache_dir, oldest_entry (timestamp or None), newest_entry (timestamp or None)
- `clean_all() -> int` — delete all cached files and manifest, return count of entries removed. Recreate empty directories.

Use `from __future__ import annotations` at top. Import `calculate_md5` from `plasmicheck.scripts.utils`.

  <name>Task 2: Unit tests for CacheManager</name>

  <action>
Create `tests/test_cache_manager.py` with comprehensive unit tests using pytest and tmp_path fixture. Mark all tests with `@pytest.mark.unit`.

**Test categories:**

1. **Initialization tests:**
   - Creates cache directory structure (indexes/, spliced/, manifest.json)
   - Handles pre-existing cache directory gracefully
   - Size limit stored correctly

2. **Index cache tests:**
   - `get_index` returns None on cache miss
   - `put_index` + `get_index` round-trip succeeds (create temp FASTA file, put an .mmi file, get it back)
   - Cache hit logs INFO message (use caplog)
   - Cache miss logs INFO message
   - Stale entry (file deleted externally) returns None and cleans manifest
   - Size mismatch (manifest says X bytes, file is Y bytes) returns None

3. **Spliced cache tests:**
   - `get_spliced` returns None on miss
   - `put_spliced` + `get_spliced` round-trip for all three files (bam, fasta, cdna_positions)
   - Combined key uses both plasmid and human MD5 (changing either input changes key)

4. **Atomic write tests:**
   - Cached file is complete (content matches source)
   - Temp files cleaned up after successful write

5. **LRU eviction tests:**
   - No eviction when under size limit
   - Oldest entry evicted first when over limit (use tiny size_limit_gb like 0.000001)
   - Multiple entries evicted if needed
   - Evicted files are deleted from disk

6. **Manifest tests:**
   - Corrupted manifest.json (write garbage to file) handled gracefully — CacheManager still initializes
   - Manifest persists across CacheManager instances (create, put, destroy, recreate, get)

7. **Info and clean tests:**
   - `info()` returns correct counts and sizes
   - `clean_all()` removes all entries and files, returns count

Create helper fixtures: `sample_fasta(tmp_path)` that writes a small FASTA file, `sample_index(tmp_path)` that writes a dummy .mmi file (just random bytes).
