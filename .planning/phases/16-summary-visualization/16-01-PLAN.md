**`aggregate_verdicts(summary_df: pd.DataFrame) -> tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame]`**
- Filter summary_df to rows where Category == "Verdict"
- Map full verdict strings to short labels using dict:
  - "Sample is contaminated with plasmid DNA" -> "Contaminated"
  - "Sample contamination status is unclear" -> "Unclear"
  - "Sample is not contaminated with plasmid DNA" -> "Clean"
- Detect missing sample-plasmid pairs by building cross-product of all unique samples x plasmids from the FULL summary_df (not just verdict rows), then left-joining verdict data. Fill missing with "No Result".
- Return tuple of (full_verdict_df, by_plasmid_counts, by_sample_counts) where:
  - full_verdict_df: DataFrame with columns [Sample, Plasmid, VerdictShort] including No Result rows
  - by_plasmid_counts: DataFrame with plasmids as index, verdict categories as columns (from groupby+unstack with fill_value=0)
  - by_sample_counts: DataFrame with samples as index, verdict categories as columns
- Ensure column order is ["Clean", "Unclear", "Contaminated", "No Result"] (reindex with fill_value=0 for missing columns)

**`plot_verdict_bar_by_plasmid(summary_df, output_dir, static_report=False, plot_backend="plotly") -> tuple[str, str | None]`**
- Call aggregate_verdicts() to get data
- Build Plotly go.Figure() with go.Bar() traces stacked (barmode='stack')
- One trace per verdict in order: Clean, Unclear, Contaminated, No Result
- Colors from VERDICT_COLORS (import from .plotting.colors)
- Hover: use customdata with format_hover_text() showing verdict name, count, and list of sample names (capped at 10 with "...and N more")
- hovertemplate="%{customdata}<extra></extra>"
- Layout: title="Verdicts by Plasmid", xaxis_title="Plasmid", yaxis_title="Count", xaxis.tickangle=45, barmode='stack'
- Write HTML to plots_dir/verdict_bar_by_plasmid.html using fig.write_html(include_plotlyjs=False, full_html=False)
- If static_report: generate PNG via matplotlib backend (lazy import pattern matching existing code like plot_boxplot)
- Return (html_path, png_path_or_None)

**`plot_verdict_bar_by_sample(summary_df, output_dir, static_report=False, plot_backend="plotly") -> tuple[str, str | None]`**
- Same pattern as by_plasmid but grouped by sample
- Hover lists plasmid names instead of sample names
- Title: "Verdicts by Sample", xaxis_title="Sample"
- Output filenames: verdict_bar_by_sample.html/.png

Also add a private helper `_format_verdict_hover(verdict: str, count: int, name_list: list[str], max_display: int = 10) -> str` that builds the hover HTML string with truncation.

Build the hover_data dict mapping verdict -> group_name -> list of names from full_verdict_df BEFORE aggregation (so you know which samples have "No Result" for each plasmid, etc.).

Use lazy imports for pandas, plotly.graph_objects (matching the existing pattern in the file). Import VERDICT_COLORS via `from .plotting.colors import VERDICT_COLORS` at the top of the function or at module level with TYPE_CHECKING guard.

Handle empty summary_df gracefully (return ("", None) if no verdict data).
